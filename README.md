# 📚 Library Management System Using Python

## 📌 Project Overview

The **Library Management System** is a Python-based, menu-driven application designed to manage library books efficiently.

It allows users to add books, search for books, issue books, return books, display available books, and save library records.

The project focuses on implementing **Object-Oriented Programming (OOP)** concepts, data structures, and file handling in Python.

## 🚀 Features

- **Add Books** – Add new books with their title, author, and unique serial number.
- **Search Books** – Search for books using their title or serial number.
- **Issue Books** – Issue available books and update their availability.
- **Return Books** – Return previously issued books to the library.
- **Display Available Books** – View books currently available in the library.
- **Save Records** – Store book information for future use.

## 🛠️ Technologies Used

- **Programming Language:** Python 3
- **Programming Paradigm:** Object-Oriented Programming (OOP)
- **Data Structures:** Lists
- **File Handling:** Reading and writing records
- **Interface:** Command-Line Interface (CLI)

## 🧠 OOP Concepts

| Concept | Description |

| Abstraction | Defines common functionality using abstract classes and methods |

## ⚙️ Installation and Setup

**Step 1: Clone the repository**

```bash

```

**Step 2: Navigate to the project directory**

```bash

```

## 🔄 How the System Works

1. The user selects an option from the main menu.
2. The system performs the selected library operation.
3. Book details are managed using Python objects and lists.
4. When a book is issued, its status changes to unavailable.
5. When a book is returned, it becomes available again.
6. Book records can be saved for future use.
